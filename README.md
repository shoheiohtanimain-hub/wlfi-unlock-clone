# WLFI Unlock — Static Clone

A single-file, self-contained clone of [worldlibertyfinancial.com/unlock](https://worldlibertyfinancial.com/unlock).

- `index.html` — the full page with all CSS, images, and fonts inlined. Open it directly in any browser; no server or internet needed.
- Built as a static snapshot for educational/personal purposes. All original content, branding, and rights belong to World Liberty Financial.

## Pages
Host it anywhere static (e.g. GitHub Pages): Settings → Pages → deploy from `main`.
